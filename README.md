# CS 240 Assignment 1

## The Repository

This repository holds the code and files needed for assignment 1 in the CS 240 class. There are 5 problems in this assignment.

## Problem 1: ASCIIToDecimal

This problem was about creating code that can convert from ASCII characters to their decimal values. 

## Problem 2: NumberBaseConverter

This problem was about creating a converter between the different number bases (hex, binary, decimal, and octal). 

## Problem 3: ImageReader
This problem dealt with getting a text file of the pixels in an image by reading that image. The image that I used, named "smile.png", is provided in the GitHub repo and the resulting text file named "awesome_picture.txt" is also in the repo. 


## Problem 4: ImageWriter
This problem is the opposite of problem 3. It was having a text file that contained hexcode and converting it to an image. The image would write over the "smile.png" file, while the file that contained the hexcode was named "the_image.txt".


## Problem 5: Edge Cases
This problem was solely related to problem 2 and dealt with checking the test cases (0, largest supported unsigned value, and one negative two's complement)
